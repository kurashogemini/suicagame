# 🍉 スイカゲーム (Suika Game) - Web MVP

HTML5, Modern CSS, JavaScript (ES Modules), および [Matter.js](https://brm.io/matter-js/) 物理演算エンジンを使用して開発された、ブラウザで遊べるスイカゲームのMVP実装です。

---

## ✨ 主な機能と特徴

1. **Matter.js によるリアルタイム物理シミュレーション**
   - フルーツの落下・回転・弾み（反発・摩擦）・衝突判定をスムーズに再現。
   - マウス、タッチ操作（スマートフォン/タブレット）、キーボード操作（矢印キー / スペースキー）に対応。

2. **11段階のフルーツ進化システム**
   - 🍒 さくらんぼ ➔ 🍓 いちご ➔ 🍇 ぶどう ➔ 🍊 デコポン ➔ 柿 かき ➔ 🍎 りんご ➔ 🍐 なし ➔ 🍑 もも ➔ 🍍 パイナップル ➔ 🍈 メロン ➔ 🍉 スイカ
   - 同じフルーツ同士が接触すると合体し、1ランク上のフルーツへ進化＋スコア加算。
   - スイカ同士の合体で大量ボーナス得点（+4096pt）＆演出発生！

3. **Web Audio API 効果音（外部ファイル不要）**
   - 落下音、合体ポップ音（階層ごとのピッチ変化）、スイカ完成ファンファーレ、ゲームオーバー音、ボタン操作音を動的生成。
   - サウンドON/OFFトグル付き。

4. **演出 & UI/UX**
   - 合体時の星型スパーク粒子エフェクトおよび浮遊スコア表示。
   - スイカ完成・ハイスコア達成時の紙吹雪演出 (`canvas-confetti`)。
   - 危険ライン監視（フルーツが溢れると警報パルス発令、2秒オーバーでゲームオーバー）。
   - ハイスコアの自動保存 (`localStorage`)。
   - 進化チャート・あそびかた説明モーダル完備。

---

## 🛠️ 開発・実行環境

- **Node.js**: v24.14.0
- **ビルドツール**: Vite 8.2.0
- **主要ライブラリ**: `matter-js`, `canvas-confetti`

### インストールと起動

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# 生産用ビルド
npm run build
```
